Automatic updates

Save a GitHub token here and this page fetches fresh headlines on its own every few minutes while it's open, and whenever you reload it.

How to create the token
  1. Open GitHub's new fine-grained token page.
  2. Name it (e.g. newsdash) and pick an expiration.
  3. Repository access: Only select repositories, then choose this repository.
  4. Permissions: add Actions and set it to Read and write. Nothing else is needed.
  5. Generate the token, copy it and paste it below.

Updates pause while the window is minimized or the tab is in the background, and catch up when you come back. Reloading also starts an update if the data is more than 2 minutes old. The token is stored in this browser only.
